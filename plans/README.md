## Findings Planned

- Correctness: clipboard-only injection can restore the previous clipboard before
  the target app consumes Cmd+V, causing random stale paste output.
- Correctness: active recorder input selection lacks the virtual/loopback device
  filter that exists in an unused hook.
- Product/UX: tray left-click opens the main window instead of a quick menu and
  lacks language/recent-history actions.
- Correctness: number formatting is inconsistent because common number
  normalization is left to provider/LLM behavior.
- Product/correctness: language settings are not provider-aware, especially for
  Hinglish and local English-only Whisper models.

## Findings Considered And Not Planned In This Batch

- Full DictationService target-recapture refactor: valid, but riskier than the
  clipboard timing bug and should follow the plan 001 regression tests.
- Acoustic speaker bleed cancellation: valid product direction, but the immediate
  code-backed bug is input-device selection. True acoustic echo cancellation may
  require native audio session work and manual macOS testing.
- Full microphone selector UI: useful, but larger than the first fix. Plan 002
  keeps UI changes limited to honest copy unless a selector can be added without
  expanding scope.
- Broad provider prompt redesign: not planned because deterministic cleanup and
  provider-aware language contracts are safer first steps.
